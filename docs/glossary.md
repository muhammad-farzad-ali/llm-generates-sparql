# Glossary

## Terms

| Term | Definition |
|------|------------|
| **DBLP** | Computer science bibliography database at dblp.org |
| **KG** | Knowledge Graph - structured data in subject-predicate-object triples |
| **SPARQL** | Query language for RDF data (like SQL for knowledge graphs) |
| **Triple** | (subject, predicate, object) statement in RDF |
| **URI** | Uniform Resource Identifier - unique identifier for entities |
| **Entity Linking** | Mapping text mentions to knowledge base URIs |
| **Schema** | Definition of classes, properties, and their relationships |
| **Ontology** | Formal description of knowledge in a domain |
| **Few-shot** | Providing examples in the prompt for LLM learning |
| **RAG** | Retrieval-Augmented Generation |

## DBLP-Specific Terms

| Term | Definition |
|------|------------|
| **Creator** | DBLP class for authors/editors |
| **Stream** | Publication venue (conference, journal, etc.) |
| **Signature** | Link between publication and creator |
| **authoredBy** | Property linking publication to author |
| **publishedInStream** | Property linking publication to venue |

## Pipeline Terms

| Term | Definition |
|------|------------|
| **Grounding** | Providing real-world context (schema, entities) to LLM |
| **Validation** | Checking query correctness before execution |
| **Repair** | Automatically fixing failed queries |
| **Confidence** | Score indicating likelihood of correctness |

## Abbreviations

| Abbreviation | Full Form |
|--------------|-----------|
| NL | Natural Language |
| KG | Knowledge Graph |
| SPARQL | SPARQL Protocol and RDF Query Language |
| RDF | Resource Description Framework |
| URI | Uniform Resource Identifier |
| API | Application Programming Interface |
| LLM | Large Language Model |
